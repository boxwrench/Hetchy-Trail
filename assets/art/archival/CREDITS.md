# Archival Image Credits

SFPUC archival photographs and documents go in this folder. Every image added
here must get a row in this table before it ships in a build.

Images are linked to cards **by filename**, not by an editor property. Name the
file `<event_id>.png` and place it in `assets/art/cards/`; the card finds it.
Find a card's `event_id` on the first line of its file in `content/cards/`.

Godot must import a newly added image before the game can load it. Either open
the project in the editor once, or run:

    godot --headless --import
