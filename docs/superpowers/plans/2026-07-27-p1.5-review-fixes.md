### Task 4: Make the validator as strict as its spec promises

**The defect.** Design spec §6 promises that *"an unknown flag, a missing
choice, a bad tier mapping, or a malformed row halts the import."* The importer
checks required keys, empty required sections, and `canonical_choice` range —
but silently accepts unknown flags, unknown frontmatter keys, misspelled effect
names, duplicate `event_id`s, and out-of-range numbers.

The worst case is quiet: a historian typing `fund: -1` instead of `funds: -1`
produces no error. The line fails the effect-key match and is swallowed into the
outcome prose. Since historian editability is the point of this pipeline, the
validator has to earn that trust before review begins.

- [ ] **Step 5: Catch misspelled effect names**

A line like `fund: -1` currently falls through into the outcome prose. Inside a
Choice section, any line that looks like `word: value` and is *not* a known
effect key is almost certainly a typo. In the body loop, replace:

```gdscript

			buffer.append(raw)
```

with:

```gdscript
		else:
			# Inside a choice, a "word: value" line that NEARLY matches an effect
			# key is almost always a misspelling. Silently treating it as prose is
			# how "fund: -1" used to vanish into the outcome text.
			#
			# Deliberately narrow: it fires only on near-misses, not on any
			# "word:" line, so ordinary prose like "Verdict: the board refused"
			# stays legal. Historians write sentences; the check must not punish
			# them for it.
			if choice != null and raw.strip_edges() != "":
				var c := raw.find(":")
				if c > 0:
					var maybe := raw.substr(0, c).strip_edges()
					if maybe.length() < 20 and not maybe.contains(" ") and not EFFECT_KEYS.has(maybe):
						var near := _near_effect_key(maybe)
						if near != "":
							errors.append("%s line %d: '%s:' is not an effect name -- did you mean '%s:'?" % [name, i + 1, maybe, near])
							return null
			buffer.append(raw)
```

Add this helper at the end of the file, next to `_split()`:

```gdscript
## The effect key a token was probably meant to be, or "" if it looks like
## ordinary prose. Matching on a shared three-letter stem catches "fund",
## "crews" and "suport" without firing on "Verdict" or "Note".
func _near_effect_key(token: String) -> String:
	var lower := token.to_lower()
	if lower.length() < 3:
		return ""
	for key in EFFECT_KEYS:
		if lower.substr(0, 3) == String(key).substr(0, 3):
			return key
	return ""
```
